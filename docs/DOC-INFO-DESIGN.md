# 方案书：图书简介卡（点封面先看后开）

> 状态：**已实施并真机验证**（2026-10-07 实施，检查单 a–i 全过，含
> 真实点按与真实返回键）。四项决策已由用户拍板：① 交互模型 = 方案 A
> （点封面弹简介卡，动作全部入卡，封面三小钮隐藏）；② 统计行四项全要
> （摘录/总结/批注/笔记）；③ 作者走 pdf.js 元数据惰性读 + 内存缓存
> （不动 library.json）；④ 先设计书、批准后实施。
> 实施修订两处（详见 §9）：拦截器改取**最近** data-action（原 closest
> 会从动作钮爬到外层封面而误杀点击）；showModal 防重入；页数以
> progress.totalPages 兜底（库内不存 pages 字段）。

## 1. 目标与非目标

**目标**

- 点封面/书名 = 弹**简介卡**（安全的一瞥），点卡内「打开读本」才进入
  阅读——与摘录查看器「先看后编」同构的二级交互
- 三个动作（打开/编辑/删除）收进简介卡：打开为大号主按钮（彻底解决
  不显眼），编辑/删除为 34px 图标圆钮；封面三小钮在移动端隐藏，封面
  只剩封面图 + 进度环
- 简介卡聚合：书名、作者（PDF 元数据）、页数/大小/分类/标签/添加时间/
  翻开次数/进度，以及统计行（🔗 摘录 N · 📝 总结 N 章 · ✎ 批注 N 页 ·
  📄 笔记 N 篇）
- 桌面端零感知；零补丁（总数保持 40）

**非目标（本期不做）**

- 书脊视图的简介拦截（书脊是纯浏览视图，无原钮可复用，保持直开）
- 简介卡内直接编辑元数据（走既有「编辑」对话框）
- PDF 元数据入库持久化（只做会话内缓存）
- 真·内容简介/摘要（数据不存在；统计行即「沉淀概览」）

## 2. 关键决策一览

| # | 决策 | 选择 | 依据 |
|---|---|---|---|
| 1 | 封面三小钮 | **隐藏而非重做**（mobile.css `display:none`） | 动作全部入卡后封面无冗余；显眼问题由卡内大主按钮根治 |
| 2 | 卡内动作的实现 | **程序化点击卡内隐藏原钮**（`data-action` 原按钮），配一次性 bypass 旗标过自家拦截 | 编辑对话框/删除确认/打开预览/列表刷新全部复用 app.js 既有逻辑，零复制零漂移 |
| 3 | 拦截层 | 移动层捕获相 click 监听 `#docGrid`，命中 `[data-action="preview-doc"]` 即拦（stopPropagation） | 不动 app.js、不加补丁；桌面委托 handler 天然收不到 |
| 4 | 守卫 | 批量模式、书脊视图、书堆卡不拦截 | 批量点卡=勾选；书脊无原钮；书堆是 `pile-open` 不同 action |
| 5 | 全文命中 | 命中态主按钮变「打开 · 第 N 页」，bypass 点击封面直达命中页 | 现有「点封面直达第 N 页」能力不可丢（页码从 `.doc-hit` 的 title 解析，解析不到退普通打开） |
| 6 | 作者元数据 | 首开惰性读（`getDocUrl` + `getDocument().getMetadata()`）+ Map 缓存（LRU 12） | 不动 library.json（桌面互通零风险）；失败/超时/无作者 → 不显示该行 |
| 7 | 统计四项 | 摘录/总结出自 `readNoteLinks` 分计数；批注页数出自 `readAnnotations`；笔记数 = `listNotes` 总数 − 侧车记录数 | 全部现成桥接口，侧车都是小文件 |
| 8 | 封面缩略 | 直接复用卡片上已加载的封面 `<img>` src | 零额外 IO，与网格所见一致 |
| 9 | 编辑/删除点击时序 | 点卡内 ✎/🗑 **先关简介卡**再触发原钮 | 上层对话框（编辑/确认）不与简介卡叠放，返回键链干净 |

## 3. 不变量与约束（不可破）

1. **零补丁**：全部落 mobile-web 自有文件；app.js/preview.js/boot.mjs 不动。
2. **桌面零感知**：拦截、隐藏、简介卡都只在移动层；桌面 hover 三钮照旧。
3. **既有流程零复制**：打开（含全文命中跳页）、编辑、删除一律经原按钮
   触发 app.js，简介卡自身不实现任何一条业务流。
4. **批量/书脊/书堆交互不变**。
5. **数据只读**：简介卡不写任何存储（元数据缓存仅在内存）。

## 4. 交互设计

### 4.1 触发与守卫

```
点 封面 / 书名（data-action="preview-doc"）
  ├─ 批量模式中 ────────────▶ 放行（勾选）
  ├─ 书脊视图 / 书堆卡 ──────▶ 放行（pile-open 或纯浏览直开）
  └─ 封面视图 ──────────────▶ stopPropagation → 弹简介卡
```

- 捕获相监听 `#docGrid` click（app.js 的委托 handler 在冒泡相，拦不到）
- 批量模式判据：沿用 `.batch-mode` 类所在节点（实施时核实挂载点）

### 4.2 简介卡（dialog，批注弹窗尺寸哲学）

```
┌────────────────────────────────────────┐
│ [封面 72px] 《AI-Agents-in-Depth-zh-CN》 ✕ │
│              张三 · 316 页 · 11.5 MB       │
│ ──────────────────────────────────────  │
│  分类 Ai   #LLM #Agent   添加于 10-05      │
│  读到 18% · 翻开 7 次                      │
│ ──────────────────────────────────────  │
│  🔗 摘录 3   📝 总结 2   ✎ 批注 5   📄 笔记 1 │
│ ──────────────────────────────────────  │
│   [ 📖 打开读本 ]     （✎）（🗑）          │
└────────────────────────────────────────┘
```

- 尺寸 `min(84vw, 480px)` × `fit-content`（上限 `min(80vh, 720px)` 内滚动）
- 关闭：✕ / Esc / 返回键（boot 通用 dialog 链）/ 点背板
- 打开主按钮：普通态「📖 打开读本」；全文命中态「📖 打开 · 第 N 页」
- 动作行为（全部先关卡再触发）：
  - 打开 → 设 bypass 旗标 → 程序化点击该卡 `.doc-cover`（preview-doc，
    app.js 完整处理含命中跳页）
  - 编辑 → 点击原 `[data-action="edit-doc"]` 钮（既有编辑对话框）
  - 删除 → 点击原 `[data-action="del-doc"]` 钮（既有确认含笔记处理勾选）
- bypass 旗标：拦截器见旗标即放行一次并复位——简介卡自身的「打开」
  不会把点击再拦回自己

### 4.3 生命周期收口

| 路径 | 行为 |
|---|---|
| 开书后卡片被 refresh 重渲染 | 简介卡每次打开时重新取数据；动作点击时卡片若已不在 DOM → 关卡 + toast「书目已变化」 |
| 编辑/删除触发 | 先关卡，后续由 app.js 对话框/刷新接管，无残留 |
| 元数据在途关卡被关 | Promise 结果丢弃（代数作废：开卡序号比对） |
| 批量模式切入 | 简介卡若开着照常可用（动作原钮被 CSS 隐藏但程序化点击仍生效） |

## 5. 数据设计

| 字段 | 来源 | 备注 |
|---|---|---|
| 书名/页数/大小/分类/标签/添加时间/翻开次数/进度 | `getLibrary().documents` | 现成字段 |
| 作者 | `getDocUrl(id)` → `pdfjsLib.getDocument({url}).getMetadata().info.Author` | Map 缓存（LRU 12）；首开异步填充（行内「…」占位）；失败/缺失隐藏该行；加载完销毁文档 |
| 摘录 N / 总结 N | `readNoteLinks(id).records` | excerpts 非空计数 / summary 存在计数 |
| 批注 N 页 | `readAnnotations(id)` | 有笔画的页数（结构按 annotations 侧车逐页键统计） |
| 笔记 N 篇 | `listNotes(id)` 总数 − 侧车 records 数 | 自由笔记 = .md 无侧车条目 |
| 封面缩略 | 卡片 `.doc-cover-img[data-doc-id]` 的 src | 已加载位图直接引用 |

聚合计算抽纯函数 `doc-info-stats.mjs`（node 可单测）：输入
links/annotations/notes 三源 → 输出 `{ excerpts, summaries, inkPages, notes }`。

## 9. 风险与开放问题

| # | 风险 | 应对 |
|---|---|---|
| 1 | 上游 app.js 改 preview-doc 结构 → 拦截选择器漂移 | 选择器取宽松的 `[data-action="preview-doc"]` 属性；sync 后真机回归 a 项 |
| 2 | `.doc-hit` title 解析页码（命中态）是 DOM 契约 | 解析失败退普通打开（能力降级不失效）；上游若改 title 格式仅丢直达 |
| 3 | 大文件 getMetadata 首开耗时 | 行内「…」占位异步填充；getDocument 只解析交叉表区，实测百毫秒级；LRU 12 防内存 |
| 4 | 批量模式挂载点（.batch-mode 在哪个节点） | 实施时核实并写进代码注释；守卫失效的最坏表现是批量中弹卡，无数据风险 |
| 5 | 删除确认与简介卡的 dialog 叠放 | 设计已定「先关卡再触发」，无叠放；boot 的 dialog 栈兜底仍在 |
